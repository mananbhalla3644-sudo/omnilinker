1.1 PRODUCT OVERVIEW
--------------------
OmniLinker is a comprehensive data integration platform that unifies scattered 
data sources across social media, cloud storage, messaging platforms, email 
systems, note-taking apps, and browsing history into a single, intelligent 
dashboard. The tool leverages graph-based visualization to reveal hidden 
relationships between people, files, conversations, and events, providing 
actionable insights through AI-powered analysis.

1.2 KEY VALUE PROPOSITION
-------------------------
- **Unified View**: Break down data silos across 10+ platforms
- **Relationship Discovery**: Automatically identify connections users are unaware of
- **Cross-Platform Search**: Natural language queries across all integrated sources
- **Privacy-First Design**: Local-first processing with user-controlled permissions
- **Scalable Architecture**: Dockerized microservices ready for cloud deployment

- Corporate knowledge management (Slack + Email + Drive integration)
- Personal productivity (WhatsApp/Telegram + Notion + Notes sync)

- Manages OAuth2 flows for all external platforms
- Stores refresh tokens and scopes in PostgreSQL
- Issues JWTs for API access (1-hour expiry)
- Handles token rotation and refresh logic

2.3.2 USER SERVICE
- User profile management (preferences, dark/light mode)
- Permission matrix storage (which sources linked to which user)
- Session management and revocation
- Email/phone verification for new users

2.3.3 SYNC SERVICE
- Handles batch data imports (nightly cron jobs)
- Manages real-time webhook connections
- Deduplicates incoming data
- Version control for imported documents
- Conflict resolution strategy (last-write-wins with audit trail)

2.3.4 GRAPH SERVICE
- Neo4j GraphQL wrapper
- Cypher query optimization
- Relationship type management
- Graph clustering algorithms (Louvain, Leiden)
- Node degree/centrality calculations

2.3.5 SEARCH SERVICE
- Elasticsearch cluster for full-text search
- Hybrid search: BM25 (keywords) + Dense Vector (semantic)
- Multi-source filtering capabilities
- Date range queries
- Faceted search (source type, person, topic)

2.3.6 AI SERVICE
- LLM integration (local or cloud endpoints)
- Conversation summarization pipelines
- Entity extraction for relationship suggestions
- Topic clustering using LDA/BERTopic
- Predictive deadline detection

2.3.7 ANALYTICS SERVICE
- Timeline event aggregation
- Frequency analysis across sources
- Correlation detection
- Anomaly detection (unusual communication patterns)

class GmailConnector(EmailConnector):
    API_VERSION = "v1"
    SCOPES = ["https://www.googleapis.com/auth/gmail.readonly",
              "https://www.googleapis.com/auth/gmail.send"]
    
    async def authenticate(self) -> bool:
        """Implement Google OAuth2 flow"""
        from google.oauth2.credentials import Credentials
        import google.auth.transport.requests
        
        auth_request = google.auth.transport.requests.Request()
        self.tokens['refresh_token'].refresh(auth_request)
        return True
    
    async def fetch_inbox(self, folder: str = "INBOX", 
                         label: Optional[str] = None) -> List[Dict]:
        """Fetch emails with attachments and metadata"""
        service = build('gmail', 'v1', 
                       credentials=self.tokens['refresh_token'])
        messages_result = service.messages().list(
            userId='me',
            pageToken=self.last_sync.get('pageToken') or None,
            maxResults=50,
            q=f"'{label}' in:labels" if label else None
        ).execute()
        
        processed_emails = []
        for msg in messages_result['messages']:
            email_id = msg['id']
            raw_message = service.users().messages().get(
                userId='me', messageId=email_id,
                format='full'
            ).execute()
            
            email_data = {
                'platform': 'gmail',
                'message_id': raw_message['id'],
                'thread_id': raw_message.get('threadId'),
                'subject': raw_message['payload']['headers'][0]['value'],
                'sender': self._parse_email(raw_message['payload']['headers'][0]),
                'recipients': self._parse_emails(
                    raw_message['payload']['headers']
                ),
                'body': self._extract_text(raw_message),
                'html_body': raw_message.get('payload', {}).get('parts', [])[-1].get('body', {}).get('data') if len(raw_message.get('payload', {}).get('parts', [])) > 0 else None,
                'attachments': self._parse_attachments(raw_message),
                'labels': [h['value'].replace('Label ', '') 
                          for h in raw_message['payload']['headers'] 
                          if h['name'] == 'Label' or h['name'] == 'Labels'],
                'date': datetime.fromtimestamp(
                    raw_message['internalDate'] / 1000
                ).isoformat(),
                'read': any(h['value'].startswith('READ') for h in 
                          raw_message['payload']['headers']),
                'size_bytes': raw_message.get('sizeEstimate', 0)
            }
            processed_emails.append(email_data)
        
        if self.last_sync:
            self.last_sync['pageToken'] = messages_result.get('nextPageToken')
        
        return processed_emails
    
    def _parse_email(self, header_dict: Dict) -> Dict[str, str]:
        """Parse 'From' header into name and address"""
        from_val = header_dict['value'][0].split('<')[1].split('>')[0]
        name_val = header_dict['value'][0].split(' ')[0] if header_dict['value'][0].startswith('"') else ''
        return {'name': name_val, 'address': from_val}
    
    def _parse_emails(self, headers: List[Dict]) -> List[Dict]:
        """Parse 'To', 'Cc', 'Bcc' headers"""
        email_fields = ['to', 'cc']
        emails = []
        for field in email_fields:
            if field in headers:
                header = headers[field]
                for val in header.get('value', []):
                    if '<' in val and '>' in val:
                        addr = val.split('<')[1].split('>')[0]
                        emails.append({'role': field, 'address': addr})
        return emails

from typing import Dict, List, Callable
import json
from datetime import datetime
from bson import ObjectId
from enum import Enum

class MessageEventType(Enum):
    """Event types for real-time message ingestion"""
    MESSAGE_CREATED = "message.created"
    MESSAGE_UPDATED = "message.updated"
    MESSAGE_DELETED = "message.deleted"
    MEMBER_JOINED = "member.joined_or_left"
    CHANNEL_CREATED = "channel.created"
    FILE_UPLOADED = "file.uploaded"

class MessagingConnector:
    """Base class for messaging platform connectors"""
    
    def __init__(self, config: Dict):
        self.platform = config['platform']
        self.api_base = config.get('api_base', '')
        self.webhook_endpoint = None
        
        # Event handlers for real-time updates
        self.event_handlers: List[Callable] = []
        
    def register_handler(self, event_type: MessageEventType, handler: Callable):
        """Register callback for message events"""
        self.event_handlers.append({
            'event': event_type,
            'handler': handler
        })
    
    async def authenticate(self) -> bool:
        pass
    
    async def process_webhook(self, event_data: Dict) -> None:
        """Process incoming webhook events"""
        event_type = MessageEventType(event_data.get('type', ''))
        for handler_info in self.event_handlers:
            if handler_info['event'] == event_type:
                await handler_info['handler'](event_data)

# Slack connector with events API
class SlackConnector(MessagingConnector):
    """Slack integration via Events API and Webhooks"""
    
    async def authenticate(self) -> bool:
        from requests_oauthlib import OAuth2Session
        
        auth_url = "https://slack.com/oauth/v2/authorize"
        token_url = "https://slack.com/api/oauth.access"
        
        session = OAuth2Session(None, redirect_uri=self.config['redirect_uri'])
        auth_response = session.get(auth_url + f"?state={self.state}")
        
        code = auth_response.url.split('code=')[1]
        params = {
            'code': code,
            'client_id': self.config['client_id'],
            'client_secret': self.config['client_secret']
        }
        
        token_response = requests.post(token_url, data=params)
        self.tokens.update(json.loads(token_response.text))
        return True
    
    async def subscribe_to_events(self) -> bool:
        """Subscribe to Slack events API for real-time updates"""
        auth_headers = {
            "Authorization": f"Bearer {self.tokens['access_token']}",
            "Content-Type": "application/json"
        }
        
        response = requests.post(
            f"{self.api_base}/events",
            headers=auth_headers,
            json={
                "type_whitelisted": [
                    "message.channels",
                    "channel_created",
                    "team_join",
                    "file.shared"
                ],
                "event_callback_url": self.webhook_endpoint
            }
        )
        
        return response.status_code == 200
    
    async def process_webhook(self, event_data: Dict) -> None:
        """Process Slack webhook events"""
        if event_data.get('type') == 'message.channels':
            await self._handle_message(event_data['event'])
    
    async def _handle_message(self, event_dict: Dict) -> None:
        """Handle incoming message event"""
        channel = event_dict['channel']
        user = event_dict['user'] if 'user' in event_dict else None
        
        # Extract conversation participants from thread history
        thread_messages = []
        if 'thread_ts' in event_dict:
            thread_response = requests.get(
                f"{self.api_base}/channels/{channel}/messages",
                headers={"Authorization": f"Bearer {self.tokens['access_token']}"},
                params={'around': event_dict['thread_ts'], 'limit': 50}
            )
            thread_messages = thread_response.json().get('messages', [])
        
        message_data = {
            'platform': 'slack',
            'channel_id': channel,
            'user_id': user,
            'username': event_dict.get('user', {}).get('name'),
            'text': event_dict.get('text', ''),
            'ts': datetime.fromtimestamp(event_dict['ts'] / 1000).isoformat(),
            'is_threaded': 'thread_ts' in event_dict,
            'thread_messages': thread_messages,
            'attachments': event_dict.get('attachments', []),
            'reactions': event_dict.get('reactions', []),
            'files': self._parse_files(event_dict)
        }
        
        # Trigger handlers
        for handler_info in self.event_handlers:
            if handler_info['event'] == MessageEventType.MESSAGE_CREATED:
                await handler_info['handler'](message_data)

class EvernoteConnector(NotesConnector):

        self.access_token = json.loads(token_response.text)['access_token']
        return True
    
    async def fetch_notes(self) -> List[Dict]:
        """Fetch notes from Evernote notebooks"""
        auth_headers = {
            "Authorization": f"Bearer {self.access_token}"
        }
        
        notes = []
        notebook_list_response = requests.get(
            f"{self.api_base}/v2/notebooks",
            headers=auth_headers
        )
        
        notebooks = notebook_list_response.json().get('notebooks', [])
        
        for notebook in notebooks:
            # Check if user has access to this notebook
            if self._can_access(notebook):
                notebook_response = requests.get(
                    f"{self.api_base}/v2/notebooks/{notebook['guid']}/notes",
                    headers=auth_headers
                )
                
                notebook_notes = notebook_response.json().get('notes', [])
                
                for note in notebook_notes:
                    # Fetch full note with EDN content
                    note_response = requests.get(
                        f"{self.api_base}/v2/notes/{note['guid']}",
                        headers=auth_headers
                    )
                    
                    if note_response.status_code == 200:
                        note_data = note_response.json()
                        
                        # Parse EDN content
                        edn_content = self._parse_edn(note_data.get('content', b''))
                        
                        notes.append({
                            'platform': 'evernote',
                            'universal_id': self._generate_universal_id(
                                note['guid'], 
                                {'notebook_id': notebook['guid']}
                            ),
                            'original_id': note['guid'],
                            'title': note.get('title', ''),
                            'notebook_name': notebook.get('name', ''),
                            'created_at': datetime.fromtimestamp(
                                note['created'] / 1000
                            ).isoformat(),
                            'updated_at': datetime.fromtimestamp(
                                note['lastUpdated'] / 1000
                            ).isoformat(),
                            'tags': self._parse_tags(note.get('tagNames', [])),
                            'content_type': 'edn' if note.get('content') else 'html',
                            'content': note_data.get('content', b''),
                            'resources': note_data.get('resources', [])
                        })
        
        return notes
    
    def _parse_edn(self, edn_bytes: bytes) -> Dict:
        """Parse Evernote EDN format"""
        try:
            import ednlib  # pip install ednlib
            edn_dict = ednlib.decode(edn_bytes)
            
            return {
                'title': str(edn_dict.get('Title', '')),
                'content': str(edn_dict.get('Content', '')),
                'attributes': self._parse_attributes(edn_dict.get('@attributes', {}))
            }
        except ImportError:
            # Fallback to string parsing
            return {'title': '', 'content': str(edn_bytes.decode()), 'attributes': {}}

def execute_search_natural_language(query: str) -> SearchResults:
    
    # Extract entities and keywords

        outlook_search = search_outlook(

        )
        results.extend(outlook_search)
    
    # Enrich with file attachments
    attached_files = []
    for email in results:

```cypher
// Centrality-based relationship analysis
MATCH (me:Person {email: 'john.doe@example.com'})
CALL apoc.path.subgraphNodes(me, {maxLevel: 1}) YIELD nodes AS connected_nodes
WHERE connected_nodes[0] <> me

WITH me, connected_nodes, collect(connected_nodes) AS people_list
MATCH (p:Person) WHERE p IN people_list
OPTIONAL MATCH (p)-[:MESSAGE]->(:Message)
WITH p, size((p)-[:MESSAGE]->()) as message_count, date(p.last_message) as last_contact
ORDER BY message_count DESC

RETURN p.display_name AS person,
       message_count AS messages_sent,
       last_contact,
       collect(DISTINCT (p)-[:MESSAGE]->(m)) AS recent_conversations
LIMIT 10;
```

7.4 API SECURITY IMPLEMENTATION

```python
# Security middleware for API routes
from fastapi import Request, HTTPException
from pydantic import BaseModel
from typing import Dict, Any
import jwt

class RateLimitConfig:
    requests_per_minute = 60
    requests_per_hour = 1000

class SecurityMiddleware:
    
    def __init__(self):
        self.rate_limits = {}
        
    async def authenticate_request(self, request: Request) -> bool:
        """Validate JWT token from Authorization header"""
        auth_header = request.headers.get("Authorization")
        
        if not auth_header or not auth_header.startswith("Bearer "):
            raise HTTPException(status_code=401, detail="Invalid authentication")
            
        token = auth_header.split(" ")[1]
        try:
            payload = jwt.decode(
                token,
                options={"verify_signature": True},
                algorithms=["HS256"]
            )
            
            # Check token expiry
            if datetime.fromtimestamp(payload['exp']) < datetime.utcnow():
                raise HTTPException(status_code=401, detail="Token expired")
                
            return payload
            
        except jwt.ExpiredSignatureError:
            raise HTTPException(status_code=401, detail="Token expired")
        except jwt.InvalidTokenError:
            raise HTTPException(status_code=401, detail="Invalid token")
    
    async def check_rate_limit(self, user_id: str, endpoint: str) -> bool:
        """Check rate limit for API endpoint"""
        key = f"{user_id}:{endpoint}"
        
        now = datetime.utcnow()
        
        # Clean up expired requests
        self.rate_limits[key] = [
            t for t in self.rate_limits.get(key, []) 
            if now - t < timedelta(minutes=1)
        ]
        
        # Check against limit
        if len(self.rate_limits[key]) >= RateLimitConfig.requests_per_minute:
            raise HTTPException(status_code=429, detail="Rate limit exceeded")
            
        self.rate_limits[key].append(now)
        return True
    
    def add_security_headers(self, response: Response):
        """Add security headers to all responses"""
        response.headers["X-Content-Type-Options"] = "nosniff"
        response.headers["X-Frame-Options"] = "DENY"
        response.headers["X-XSS-Protection"] = "1; mode=block"
        response.headers["Referrer-Policy"] = "strict-origin-when-cross-origin"
        return response

```
